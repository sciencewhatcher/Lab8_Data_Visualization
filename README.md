Data visualization of the Top 1000 Most Played Spotify Songs using Matplotlib and Seaborn.

## Contents
- `Activity8_Data_Visualization.ipynb`: main activity (setup, 6 core visualizations, 20 student-personalized plots)
- `yearly_popularity_trend.gif`: animated line chart of average popularity over time
- Additional Exercises (Appendix E) are on the
  [`activity8-additional-exercises`](https://github.com/sciencewhatcher/Lab8_Data_Visualization/tree/activity8-additional-exercises) branch

## How to run
1. `python -m venv .venv`, then activate it
2. `pip install pandas numpy matplotlib seaborn pillow ipykernel`
3. Download the dataset from [Kaggle](https://www.kaggle.com/datasets/kunalgp/top-1000-most-played-spotify-songs-of-all-time)
   and place `spotify_top_1000_tracks.csv` in a `spotify_dataset/` folder
4. Open the notebook in VS Code, select the `.venv` kernel, and run all cells

The dataset is not included in this repository.
